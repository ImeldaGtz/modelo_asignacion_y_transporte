# Página para resolver problemas lineales mediante modelo de asignación y transporte

### Objetivo
Se busca una página que permita, valga la redundancia, resolver problemas lineales mediante los modelos especificados.
Se sabrá si es de asignación o de transporte mediante un botón que hará de switch entre "Asignación" y "Transporte".

#### Requerimientos
Se identifican la/s:
* Variables
* Función objetivo
* Restricciones
* Valor de las variables

Se puede/n cambiar:
* Modelo
* Variables
* Identificadores
